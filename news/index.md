## aiimsulator 0.1.0

- Initial development package with estimation, comparison, AUC,
  diagnostic accuracy, correlation and Yamane planning functions.
- Independent selectable general equations, numerical substitutions,
  results, assumptions and references for Markdown, LaTeX and plain-text
  reporting.
- Optional design effects and finite population corrections for
  single-group estimators; explicit warnings where approximations have
  design limitations.
- Added independent tabulated regression tests, equation API tests and
  cross-platform package-check workflow (execution pending).
